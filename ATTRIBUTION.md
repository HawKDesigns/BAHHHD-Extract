# Attribution

## Extractor

BAHHHD-Extract is an independent utility released by **HawKDesigns** under the [MIT license](LICENSE). It uses the Python standard library; no third-party Python packages or external source files are bundled.

The archive parser and decompressor implement the observed Bark 1.06 layout and an Okumura-style LZSS scheme. “Okumura-style” describes the compression technique; this repository does not include Haruhiko Okumura's LZSS source code.
